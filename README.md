# 巡星记 · Solar Odyssey

单文件 Three.js 太阳系模拟器。所有内容（物理引擎、星历、纹理、UI）都内嵌在 `index.html` 中，双击即可在浏览器打开，无需构建、无需联网、无依赖。

面向天文与数学启蒙：可以手动调参数发射火箭，观察真实的轨道力学行为。

## 运行方式

### 方式一：直接打开

双击 `index.html`，或把它传到平板上用浏览器打开。

### 方式二：局域网共享（电脑起服务，平板看）

- Windows：双击 `启动服务器-Windows.bat`
- macOS：双击 `启动服务器-Mac.command`

黑窗口里会显示形如 `http://192.168.1.5:8080` 的地址，在同一 Wi-Fi 下的平板浏览器输入即可。黑窗口不要关，关了服务就停。

> 平板和电脑必须连同一个路由器；手机热点和家里 Wi-Fi 不是同一个网会打不开。

## 物理与数值方法

单位制统一采用 **AU（天文单位）/ 年（yr）**，所有积分在该单位制下进行以避免量级问题。

| 量 | 值 |
|---|---|
| `MU_SUN` | `4π²` AU³/yr² |
| `MU_EARTH` | `1.18e-4` AU³/yr² |
| `R_EARTH` | `6371 km` → AU |
| `SOI_EARTH` | `0.0062` AU（地球引力影响球边界） |

- **发射段（主动段）**：RK4 积分，程序带"重力转弯"（gravity turn），逐步把推力方向从垂直转向水平。
- **滑行段 / 日心段**：速度 Verlet（辛积分），步长自适应 `∝ r^1.5`。
- **入轨捕获**：PATCHED-CONIC（圆锥拼接）——地球引力圈 → 日心转移 → 目标引力圈捕获。
- **行星位置**：JPL 近似星历（`keplerPos`），由日期驱动；卫星用圆轨道近似。
- **时间推进**：按时间而非按路径点推进，保证开普勒第二定律成立（近地点快、远地点慢）。

## 四种预设任务

| 预设 | 说明 |
|---|---|
| **环绕** | 近地椭圆轨道（远地点约 14400 km）。真实卫星多为近圆轨道，本项目为单次点火的"转移轨道型"椭圆。 |
| **逃逸** | 以第三宇宙速度量级逃离太阳系。 |
| **去月球** | 奔月转移 → 月球引力捕获 → 绕月飞行（周期约 1.2 天）。 |
| **去火星** | 霍曼转移 → 火星引力捕获 → 绕火飞行（日心远日点 1.522 AU，绕火周期约 1.26 天）。 |

发射参数（主动段推力加速度 g、点火时长 b、发射方位角）均可实时调整，轨迹会随之改变；若参数设置不当，火箭会坠落——这本身就是真实的。

## 已知的理想化处理

诚实标注，避免误导使用者：

1. **发射窗口被理想化**：月球/火星被对齐到转移轨道的终点方向，使轨迹连续。真实的行星际转移需要等待相位窗口（如火星约每 26 个月一次）。
2. **入轨为高偏心椭圆**：单次点火的必然结果。真实卫星要靠第二次"圆化变轨"点火才能进入近圆轨道。
3. **逃逸未实现引力弹弓**：目前为直接逃逸，未模拟旅行者号式的行星借力加速。
