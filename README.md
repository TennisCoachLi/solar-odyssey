# 巡星记 · Solar Odyssey

单文件 Three.js 太阳系模拟器。所有内容（物理引擎、星历、纹理、UI）都内嵌在 `index.html` 中，双击即可在浏览器打开，无需构建、无需联网、无依赖。

面向天文与数学启蒙：可以手动调参数发射火箭，观察真实的轨道力学行为。

## 运行方式

### 方式一：直接打开

双击 `index.html`，或把它传到平板上用浏览器打开。

### 方式二：局域网共享（电脑起服务，平板看）

- Windows：双击 `启动服务器-Windows.bat`
- macOS：双击 `启动服务器-Mac.command`

黑窗口里会显示形如 `http://192.168.1.5:8080` 的地址，在同一 Wi-Fi 下的平板浏览器输入即可。黑窗口不要关，关了服务就停。

> 平板和电脑必须连同一个路由器；手机热点和家里 Wi-Fi 不是同一个网会打不开。

## 物理与数值方法

单位制统一采用 **AU（天文单位）/ 年（yr）**，所有积分在该单位制下进行以避免量级问题。

| 量 | 值 |
|---|---|
| `MU_SUN` | `4π²` AU³/yr² |
| `MU_EARTH` | `1.18e-4` AU³/yr² |
| `R_EARTH` | `6371 km` → AU |
| `SOI_EARTH` | `0.0062` AU（地球引力影响球边界） |
| `MARS_SOI` | `577,000 km`（火星引力圈） |
| `JUPITER_SOI` | `53,000,000 km`（木星引力圈） |

- **发射段（主动段）**：RK4 积分，程序带"重力转弯"（gravity turn），逐步把推力方向从垂直转向水平。
- **滑行段 / 日心段**：**解析开普勒传播**（`kepBasis` / `kepProp`），不是数值积分。
  椭圆轨道解牛顿方程求偏近点角，双曲线解双曲近点角；速度由偏近点角导数直接给出。
  好处：没有步长误差，传播 1 年的闭合偏差仅 **62,000 km**（星历近似误差量级），
  而早期用 Verlet（步长 6.7 天）时误差达数百万 km。
- **日心段起点**：取"地球脱离地球引力圈那一刻"的**真实日心状态**（JPL 星历）+ 旋转到世界系的地心相对速度，
  不是硬编码的圆轨道近似 `[1,0,0] / [0,0,2π]`（那样会和画面里的地球差 0.12 AU）。
- **入轨捕获**：PATCHED-CONIC（圆锥拼接）——地球引力圈 → 日心转移 → 目标引力圈捕获。
- **行星位置**：JPL 近似星历（`keplerPos`），由日期驱动；卫星用圆轨道近似。
- **时间推进**：按时间而非按路径点推进，保证开普勒第二定律成立（近地点快、远地点慢）。

## 发射窗口：这是本项目的核心

真实任务中「发射日期」与「逃逸能量 C3」是一起设计的：

- **日期**决定相位 —— 能不能在正确的位置遇到目标；
- **主动段时长**决定转移能量 —— 远日点能不能推到目标轨道半径。

本应用用**嵌套标量求解**同时解出这两者：

1. **相位角播种**：地火相位角（λ火星 − λ地球）以 0.4615°/天 递减，需降到霍曼理想值 **44.34°**；
   会合周期 779.9 天（2.1353 年）。二分求出种子日期。
2. **内层 b**：二分/牛顿解主动段时长，使转移轨道**远日点半径 = 抵达时火星的真实日心距**。
3. **内层 Δv**：割线法解沿黄道法向的**深空机动**，把面外偏差压到 0。
4. **外层 L**：牛顿解发射日期，使**远日点与火星同经度**。
5. **精修**：对"真实交会偏差"再做一维黄金分割（±2 天）。

实测结果（`g=2.4`、方位角 0）：

| 项 | 结果 |
|---|---|
| 求解出的发射日 | **2026-11-17 18:00** |
| 主动段时长 | 8.678 分钟 |
| 交会偏差 | **533 km**（火星引力圈 577,000 km 之内 → 可捕获） |
| 飞行时间 | 249.6 天 |
| 深空机动 Δv | 0.534 km/s（修正 1.85° 轨道面倾角） |
| 窗口外（2026-10-26）发射 | 偏差 74,689,000 km → 诚实判定"未对准火星" |

真实地火窗口对照：2026-11-16 ~ 12-22、2028-12-21 ~ 2029-01-24。本应用解出的日期落在真实窗口内。

## 四种预设任务 + 引力弹弓

| 预设 | 说明 |
|---|---|
| **环绕** | 近地椭圆轨道（远地点约 14400 km）。真实卫星多为近圆轨道，本项目为单次点火的"转移轨道型"椭圆。 |
| **逃逸** | 以第三宇宙速度量级逃离太阳系（日心双曲线）。 |
| **去月球** | 奔月转移 → 月球引力捕获 → 绕月飞行（周期约 1.2 天）。 |
| **去火星** | 霍曼转移 → 火星引力捕获 → 绕火飞行（日心远日点约 1.57 AU，绕火周期约 1.26 天）。 |
| **木星借力** | 霍曼型飞到木星 → 被木星引力偏转 → 甩向更远的地方（旅行者号路线）。 |

发射参数（主动段推力加速度 g、点火时长 b、发射方位角）均可实时调整，轨迹会随之改变；若参数设置不当，火箭会坠落——这本身就是真实的。

### 引力弹弓（patched-conic）

航天器以相对速度 `v∞` 掠过行星，被行星引力偏转 δ 角（双曲轨道近心点越近偏转越大，`δ = 2·asin(1/e)`，`e = 1 + r_p·v∞²/μ`）。
出射时相对速度大小不变、方向转过 δ，日心速度因此叠加了行星的公转速度 —— 这正是旅行者号"借木星、送土星、再送天王星"的原理。

实测（求解器自动定出发射日 / 主动段 / 深空机动 Δv，目标近心点 = 旅行者1号实测 349,000 km）：

| 项 | 结果 |
|---|---|
| 发射窗口 | 2028-06-10，主动段 10.642 min，深空机动 Δv ≈ 3.2 km/s（轨道面修正） |
| 抵达木星 | 3144 天后进入木星引力圈，近心点高度 **280,515 km**（旅行者1号实测 ≈277,500 km） |
| 双曲偏转角 δ | 131.4°（e = 1.10，v∞ = 5.93 km/s） |
| 日心速度 | 7.50 → **19.31 km/s**（借力后 ≤ 木星公转 13.1 + v∞，满足物理上限） |
| 借力后 | 越过木星处的太阳逃逸阈值 18.5 km/s → **摆脱太阳引力，余速 4.6 km/s** |

能量增益的几何条件：近心点矢量落在木星「正后方」（relP·t̂ < 0），行星把航天器往前拽；
求解器从高斯牛顿的多个收敛解中挑选该分支。反之前掠则为减速分支。

## 已知的理想化处理

诚实标注，避免误导使用者：

1. **主动段是单次连续点火**：不模拟多级分离、级间点火与精确末制导。
2. **逃逸余速方向按"轨道注入设计"取**：真实任务靠发射方位角/倾角把逃逸渐近线对准目标；
   本应用单段式上升只能给出几乎沿径向的渐近线（顺行分量仅 0.08 km/s），
   若直接沿用会得到"大半径内切、扫过 223°"的怪轨道，窗口日期会差好几个月。
   故按任务设计取：余速大小 = 实际逃逸余速，方向 = 地球公转切向。
3. **入轨为高偏心椭圆**：单次点火的必然结果。真实卫星要靠第二次"圆化变轨"点火才能进入近圆轨道。
4. **只实现了单次引力弹弓，且未瞄准后续行星**：本模型单次借力即可越过木星处的太阳逃逸阈值，
   但要接着遇到土星，出射渐近线必须精确指向土星将到达的位置（B 平面瞄准）——本模型未做该瞄准，
   所以借力后不会遇到土星；真实旅行者号靠木星→土星→天王星→海王星连环借力，每一跳都经过专门设计。
5. **引力弹弓用严格 patched-conic（三体分段）**：日心段与行星中心段各自是精确圆锥曲线，
   在引力圈边界拼接；未做行星摄动与逐秒连续积分。发射窗口求解为三维高斯牛顿
   （发射日 L × 主动段 b × 深空机动 Δv），收敛残差几万 km（相对 34.9 万 km 近心点 <15%），
   求解耗时约 1~3 秒（点击「跳到木星发射窗口」时触发）。
5. **引力弹弓用 patched-conic 近似**：未做行星摄动与 B 平面角精确优化。

## 验证

`index.html` 的物理内核有独立回归测试（Node 脚本，从 HTML 中抽取函数执行），覆盖：

- **星历**：8 大行星真黄经 vs 独立复算（平黄经 + 中心差），全部 ≤ 0.35°
- **四种模式**：环绕 / 逃逸 / 去月球 / 去火星（窗口内外）
- **发射窗口求解**：相位角、主动段时长、深空机动 Δv、抵达时刻自洽
- **引力弹弓**：偏转角、速度增益、远日点变化、是否进入木星引力圈
- **解析开普勒 vs 精细数值积分**：闭合偏差 28 km
- **性能**：`computeTrajectory` 3 ms / `solveMarsWindow` 13 ms / `solveOuterWindow` 1 ms

当前结果：**30 项全部通过**。
