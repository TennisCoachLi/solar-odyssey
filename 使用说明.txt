==================================================
  巡星记 · Solar Odyssey —— 局域网共享包 使用说明
==================================================

这个文件夹里有：
  index.html                巡星记本体（全部内容都在里面）
  启动服务器-Windows.bat     双击启动（Windows 电脑用）
  启动服务器-Mac.command     双击启动（苹果电脑用）


--------------------------------------------------
【方法一】电脑开服务，平板输网址看（推荐）
--------------------------------------------------

1. 把这个文件夹整个解压出来，放在电脑桌面上。

2. 看你的电脑是什么系统：
     Windows 电脑 -> 双击「启动服务器-Windows.bat」
     苹果电脑   -> 双击「启动服务器-Mac.command」
                  （第一次打开若提示"来自身份不明的开发者"，
                    请右键点它 -> 选"打开" -> 再点"打开"）

3. 会弹出一个黑色窗口，里面写着一条地址，形如：
        http://192.168.1.5:8080
   把这条地址，原样输入到平板的浏览器里，回车。

4. 搞定。黑窗口不要关，关了服务就停了。
   下次再看，重新双击一次即可。


--------------------------------------------------
【方法二】直接把文件丢到平板上（不用电脑）
--------------------------------------------------

把 index.html 用微信 / AirDrop / U盘 传到平板上，
在用文件管理器点开它，选择"用浏览器打开"即可。

注意：有些平板自带的预览窗口对手势操作支持不好，
      如果转不动、缩不动，就用方法一。


--------------------------------------------------
【常见问题】
--------------------------------------------------

Q：平板上打不开，一直转圈？
A：确认平板和电脑连的是同一个 Wi-Fi（同一个路由器）。
   手机热点和家里的 Wi-Fi 不是同一个网，会打不开。

Q：地址里的数字（192.168.x.x）每次不一样？
A：正常，路由器每次分配的可能不同，以黑窗口里显示的为准。

Q：点了黑窗口，一闪就没了？
A：说明没装 Python，按窗口里的提示去 python.org 装一个，
   安装第一步记得勾选 "Add Python to PATH"。

Q：想关掉服务？
A：直接把那个黑色窗口关掉就行。
